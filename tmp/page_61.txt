Runtime metrics:
We report the time it took for the policies compute the rollout per each time
step in the simulation in milliseconds. The objective of this is to keep track of the real-
time computational cost of running the policies in our hardware. The aggregated values
within a given Monte Carlo set are summarized using the median and interquartile
range[Q 1, Q3].
